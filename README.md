### Reflection

During this project, the basic setup for the treasure hunt game was provided, and my responsibility was to implement the Q-learning algorithm that enabled the agent to navigate the maze and find the treasure as efficiently as possible. I developed the code beginning below the **START HERE** section, including the training loop that balanced exploration and exploitation using an epsilon-greedy strategy. By adjusting the agent's decisions through repeated training episodes, the algorithm was able to learn an optimal path through the maze.

Computer scientists solve problems by designing algorithms and developing software that addresses real-world challenges efficiently and effectively. When approaching a programming problem, I prefer to break it into smaller, more manageable pieces while keeping the overall objective in mind. This approach allows me to focus on solving one problem at a time without losing sight of the final goal. As each component is completed, the individual pieces come together to create a complete and functional solution.

Throughout this project, I gained a better understanding of reinforcement learning and how an intelligent agent can improve its decision-making through experience. Implementing the Q-learning algorithm demonstrated the importance of balancing exploration, where the agent tries new actions, with exploitation, where it applies what it has already learned to maximize rewards. This experience strengthened my problem-solving skills and gave me a greater appreciation for how artificial intelligence can be used to solve complex problems.

As a computer scientist, I also recognize my ethical responsibility to both end users and the organizations that use the software I develop. It is important to write secure, reliable, and maintainable code while considering the potential impact that software can have on people. I strive to develop applications that protect user data, operate safely and fairly, and minimize the possibility that the software could be misused or cause unintended harm.
